# Client Onboarding Checklist

## Information
- [ ] LO name, title, photo, bio
- [ ] LO NMLS # and company NMLS #
- [ ] Licensed states
- [ ] Products offered
- [ ] Office hours and handoff/transfer number
- [ ] Company address, logo, colors, email signature
- [ ] Review link (Google/Zillow)

## Access
- [ ] Calendar
- [ ] LOS (API/webhook) and POS (webhook/portal link format)
- [ ] Website for form + chat widget install
- [ ] Lead vendors

## Compliance
- [ ] Compliance officer contact
- [ ] Approved consent language
- [ ] Approved scripts and templates (sign-off date: ____)
- [ ] State-specific calling restrictions reviewed
- [ ] A2P 10DLC brand + campaign submitted (date: ____) / approved (date: ____)
- [ ] Vendor/service-provider agreement executed

## Build & launch
- [ ] Fields, tags, pipeline created
- [ ] Agents A1 to A10 configured per tier
- [ ] Workflows active per tier
- [ ] 30 test scenarios passed
- [ ] LO trained (onboarding guide reviewed)
- [ ] 2-week pilot scheduled with weekly QA review
