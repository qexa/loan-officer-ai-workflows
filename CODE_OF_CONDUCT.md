# Code of Conduct

We are committed to a welcoming, respectful, harassment-free community for everyone.

**Expected:** be kind, assume good intent, give constructive feedback, and credit others' work.

**Unacceptable:** harassment, discriminatory language, personal attacks, sharing others' private information, or posting real borrower data.

Maintainers may remove content or contributors that violate this code. Report concerns to conduct@qexa.com.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
